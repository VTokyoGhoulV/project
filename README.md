# Описание проекта

Проект предназначен для безопасной обработки банковских транзакций.

Основные возможности:

-   маскирование номеров банковских карт;
-   маскирование банковских счетов;
-   преобразование формата даты;
-   фильтрация списка операций по статусу;
-   сортировка операций по дате.

Проект написан на **Python** и соответствует стилю **PEP8**.

# Использование

## Маскирование номера карты

Функция:

    get_mask_card_number(card_number: int) -> str

Пример:

``` python
from src.masks import get_mask_card_number

print(get_mask_card_number(6831982476737658))
```

Результат:

    6831 98** **** 7658

------------------------------------------------------------------------

## Маскирование номера счета

Функция:

    get_mask_account(account_number: int) -> str

Пример:

``` python
from src.masks import get_mask_account

print(get_mask_account(73654108430135874305))
```

Результат:

    **4305

------------------------------------------------------------------------

## Маскирование карты или счета

Функция:

    mask_account_card(account_card_number: str) -> str

Пример:

``` python
from src.widget import mask_account_card

print(mask_account_card("Visa Platinum 6831982476737658"))
print(mask_account_card("Счет 73654108430135874305"))
```

Результат:

    Visa Platinum 6831 98** **** 7658
    Счет **4305

------------------------------------------------------------------------

## Форматирование даты

Функция:

    get_date(date: str) -> str

Пример:

``` python
from src.widget import get_date

print(get_date("2024-03-11T02:26:18.671407"))
```

Результат:

    11.03.2024

------------------------------------------------------------------------

## Фильтрация операций

Функция:

    filter_by_state(dict_list: list, state: str = "EXECUTED") -> list

Пример:

``` python
from src.processing import filter_by_state

operations = [
    {'id': 1, 'state': 'EXECUTED'},
    {'id': 2, 'state': 'CANCELED'}
]

print(filter_by_state(operations))
```

Результат:

    [{'id': 1, 'state': 'EXECUTED'}]

------------------------------------------------------------------------

## Сортировка операций

Функция:

    sort_by_date(dict_list: list) -> list

Пример:

``` python
from src.processing import sort_by_date

operations = [
    {'id': 1, 'date': '2019-07-03T18:35:29.512364'},
    {'id': 2, 'date': '2018-06-30T02:08:58.425572'}
]

print(sort_by_date(operations))
```
